# [v0.3.0] - 2026-05-01

## 新增

- 新增 `cmds/doccmd/` 交互式文档站命令（`doc`）：从命令树自动生成类 Swagger UI 的浏览界面，集成 Mermaid 图渲染（命令树、分发流程、MCP 时序）、命令搜索、参数/选项表格。
- 新增 `cmds/llmstxtcmd/` 命令：生成 llms.txt 格式的命令树文档（支持纯文本与 JSON 输出），供 LLM/Agent 消费。
- 新增 MCP Resources：`llms.txt` 文档资源、逐命令帮助资源、逐工具 JSON Schema 资源。
- 新增 MCP Prompts：CLI 全局概览 prompt、逐命令用法 prompt。
- 新增 MCP ToolAnnotations 支持：通过 `Command.Metadata` 声明 `agent.readonly`/`agent.idempotent`/`agent.destructive`/`agent.open-world`，自动映射到 MCP 标准注解。
- 新增 MCP Tool 超时策略：通过 `Command.Metadata` 声明 `agent.timeout`，自动应用 `context.WithTimeout`。
- 新增 Agent Hints：命令描述自动追加 agent 提示段落（只读、幂等、破坏性等）。
- 新增全局 `--list-format` 枚举标志（`text`/`json`），`--list-commands` 与 `--list-flags` 支持 JSON 输出。
- 新增 `reflectTypeSchema`：从 Go 类型自动生成 JSON Schema，支持 `time.Time`、`[]byte`、匿名字段展平。
- Stream envelope 新增 `seq`（序号）与 `ts`（毫秒时间戳）字段，便于客户端排序与延迟监控。
- MCP 工具输入 schema 新增 `x-redant-arg-modes` 扩展，标注支持的参数输入模式（positional/query/form/json）。
- MCP 值类型 schema 扩展：新增 `duration`、`url`、`regexp`、`host:port`、`json` 类型映射。

## 修复

暂无

## 变更

- `OptionSet.FlagSet()` 对默认值和环境变量值 `Set` 失败时输出 warning 到 stderr，不再静默忽略。
- 移除全局 `--env` / `-e` / `--env-file` 标志及 `env_preload.go` 环境预加载模块，避免与业务命令自定义同名标志冲突。选项级 `Envs` 环境变量回退机制不受影响。
- `ParseJSONArgs` 错误提示改为包含格式示例的可操作性信息。
- `ResponseTypeInfo.Schema` 类型从 `string` 变更为 `map[string]any`，存储自动生成的 JSON Schema 对象。
- 内部隐藏标志 `--args` 重命名为 `--redant-args`，避免与业务命令同名标志冲突。

## 文档

- README 改为"三步式黄金路径"快速开始（最小命令 → 加标志 → 加子命令）。
- 示例目录新增 `example/README.md` 分层索引（入门 → 基础 → 进阶 → 综合）。
- 更新 `docs/DOCS_CATALOG.md`，新增"可视化与文档生成"分类。
- 更新 `docs/MCP.md`，新增 Resources/Prompts/Agent Hints/Typed Response Schema/Arg Modes/Tool Timeout/Stream Envelope/List JSON 等章节。
- fastcommit 示例集成 `doccmd` 与 `llmstxtcmd` 命令。
- 弱化 `--redant-args` 内部标志在文档中的可见度，明确标注为框架内部保留标志。
- 示例 `echo`、`unary`、`stream-interactive` 补充 `Long` 详细描述与用法示例。
